# Neatsum

Finanzas familiares con IA, en tu ordenador. Antes se llamaba FinFlow.

Aquí solo hay instaladores. Descarga la última versión en
[Releases](https://github.com/tonilv/neatsum-releases/releases/latest):

- **Windows**: `Neatsum-Setup-x.y.z.exe`. Se instala encima de la versión anterior y conserva tus datos.
- **Ubuntu / Linux**: un solo comando, que elige `.deb` o AppImage según tu sistema:

```
curl -fsSL https://github.com/tonilv/neatsum-releases/releases/latest/download/instalador.sh | bash
```

La app avisa sola cuando hay una versión nueva.
